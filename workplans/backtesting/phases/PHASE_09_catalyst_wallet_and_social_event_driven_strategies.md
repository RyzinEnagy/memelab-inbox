## Required execution

- Audit existing Social & Trader Intelligence, wallet attribution, holder clustering, narratives, alerts and source credibility modules. Reuse original IDs/raw evidence, avoid parallel fake social collector. Build point-in-time catalyst features for verified announcements, original influencer posts, multi-source corroboration, coordinated bot bursts, concentrated-wallet selling/buying, LP withdrawal, authority change, public listing/market changes and volume surge.

- Emit deterministic catalyst strategy outputs (as-of evidence + verifiability + invalidation) and join with technical rules only when data is simultaneously known. Add shuffled timestamp/placebo controls and skeptical reviewer pass.
- Social sentiment must never directly bypass liquidity/fatal-flaw screens; optimize only on training periods and record tested event hypotheses.
