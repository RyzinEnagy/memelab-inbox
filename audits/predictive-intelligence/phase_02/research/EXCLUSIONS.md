# Phase 02 exclusions

Every repository that Phase 02 verified (`git ls-remote`, blob-less clone at the pin, ecosyste.ms lookup) or read, and that is not a candidate, is listed in sections A to F with its reason. Section G gives the reason each candidate is not on the shortlist. Reasons are screening facts at the pinned SHA, not scores; Phase 03 may revisit any of them. Generated by `probes/render_exclusions.py` from the recorded evidence.

Returned by a query but never selected for verification: 1877 distinct repository names across the query corpus (QUERY_RESULTS.jsonl). They were not individually screened; the selection rule was that a name, package summary or linked documentation matched a frozen need in NEEDS.csv. The GitHub search API returned HTTP 403 for all 22 queries (session proxy policy), so no repository was found or excluded through it.
