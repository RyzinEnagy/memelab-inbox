# Phase 02 acceptance checklist (written before any search)

Written 2026-10-24T02:55Z, after the entry gate and before the first discovery query, clone or API call. Each item is falsifiable; PHASE_02_EVIDENCE.md records the command and result for each. The needs that decide relevance are frozen in `research/NEEDS.csv` at the same time, from the Phase 01 records (TARGET_REGISTRY.md, ACCEPTANCE_METRICS.md, PLANNED_SEAMS.md, GAP_MATRIX.csv, DEPENDENCY_GRAPH.md), so that what a famous repository does cannot redefine what the engine needs.

| Id | Check | How it is verified | Fails if |
|---|---|---|---|
| C1 | Package unchanged | `sha256sum -c SHA256SUMS.txt` in the package folder | any line not OK |
| C2 | Entry gate | `python -m pytest tests -q` at `a402df6`, checkout clean | anything other than `1 failed, 858 passed` with only `test_dedup_corroboration_resurface_denial` failing |
| C3 | Needs frozen before searching | `research/NEEDS.csv` committed in the same commit as the results, its sha256 and write time recorded here and in the evidence before the first query time in `research/QUERY_RESULTS.jsonl`; every need names Phase 01 gap cells or seams that exist | a need added or changed after a query ran without a dated correction note, or a need that cites a cell not in GAP_MATRIX.csv |
| C4 | Query corpus | `research/SEARCH_LOG.md` and `research/QUERY_RESULTS.jsonl`: at least 12 distinct queries over at least 6 non-overlapping topic families, at least 4 discovery mechanisms (GitHub search API, PyPI JSON cross-links, paper or code links, documentation cross-links, WebSearch); each query with mechanism, exact string or URL, UTC time, HTTP status, result counts, sha256 of the raw body (raw bodies kept outside the repo) | fewer queries, families or mechanisms; a query without time, status or body hash |
| C5 | Candidates verified | `research/CANDIDATES.csv`: at least 45 unique repositories by canonical `owner/name` (case-insensitive) from the GitHub API, `fork` false, pinned SHA from `git ls-remote <url> HEAD` with `observed_at` UTC, clone HEAD equal to the pin, commit date, archived flag, discovery query ids, family, role, need ids, flags; checked by `probes/check_candidates.py` | fewer than 45, a duplicate, a fork or mirror counted, a SHA that is not 40 hex or does not match the clone, a row without discovery provenance |
| C6 | License from source | license per repository read from the LICENSE (or COPYING) file at the pinned SHA with the file's sha256, or from the API with the caveat `API_ONLY`; AGPL, GPL, non-OSI, source-available and non-commercial model-weight terms flagged; GPU, LLM and paid-service dependencies flagged from pinned dependency files or PyPI metadata, with the file or URL named | a license stated from a README alone, or a flag without a source |
| C7 | Gap linkage | every candidate names at least one need id; every need maps to GAP_MATRIX cells whose status is MISSING, PARTIAL or CONFLICT (or the PLANNED_SEAMS boundary for behavioral simulation, which has no matrix facility); the checker validates the cells against GAP_MATRIX.csv | a candidate with no need, or a need cell that is VERIFIED_PRESENT or absent |
| C8 | Shortlist | `research/SHORTLIST.csv`: at least 20 rows, a subset of CANDIDATES.csv, no score or rank; at least 3 per high-priority family where eligible (tabular probability, time series, calibration and uncertainty, online and drift, behavioral multi-agent, experiment audit and evaluation); includes `666ghj/MiroFish` and `camel-ai/oasis`; each row has an inclusion reason, the uncertainty Phase 03 must resolve, and at least one code path that exists in the tree at the pinned SHA | fewer rows or a family below 3 without a written reason; a row whose only evidence is README text |
| C9 | Exclusions | `research/EXCLUSIONS.md`: every repository screened but not a candidate, and every candidate not shortlisted, with a reason (fork, mirror, renamed or vanished, tooling, non-matching, README-only, license, out of scope) | a screened repository that appears nowhere |
| C10 | Provenance audit | five discovery rows chosen by a seeded draw (seed recorded) have their queries re-run later and the repository appears again in the new result, or the difference is recorded | fewer than five, or a row whose provenance cannot be reproduced and is still counted |
| C11 | Negative tests of the checker | `probes/check_candidates_negative.py` mutates copies of the CSVs: duplicate, fork, bad SHA, unknown need, need on a VERIFIED_PRESENT cell, README-only code evidence in the shortlist (P42), crawler as candidate, vanished repository (404), shortlisted row missing from candidates | any mutation that the checker accepts |
| C12 | P42 on a real repository | at least one repository found by a real query whose README makes predictive or accuracy claims is screened and gets no credit (excluded, reason recorded) because no evaluating code or tests back the claim at its pinned SHA | the only P42 evidence is synthetic |
| C13 | MiroFish lens | MiroFish recorded as behavioral simulation (hypothesis generation), never as numeric price-forecast evidence; its license, LLM and memory-service dependencies read from its pinned files | MiroFish counted as a forecasting model or its flags taken from the README alone |
| C14 | Crawlers | Firecrawl, Crawl4AI and Maxun are listed as tooling in EXCLUSIONS.md and are not in CANDIDATES.csv | any of them in CANDIDATES.csv |
| C15 | No production code, tracked data untouched | `git diff --name-only a402df6..HEAD` lists only `audits/predictive-intelligence/` and `docs/predictive-intelligence/`; nothing under `memelab/`, `tests/`, `inbox/`, `state/`, `data/`; full suite after shows only the known failure; strays removed by hand; `data/memelab.sqlite` sha256 unchanged | any other path, a new test failure, or a stray left |
| C16 | Spend and free-call accounting | COST_LEDGER.md row for Phase 02 (Firecrawl credits, 0 planned); free calls counted by kind in the evidence (GitHub core and search, ls-remote, clones, PyPI, WebSearch, WebFetch) | a billable call not logged |

| C18 | Records | PHASE_02_EVIDENCE.md, PHASE_02_RESULTS.json (parses), SKEPTIC_PACKET.md, ROADMAP row, HANDOFF rewritten, DECISIONS only for durable choices; status NEEDS_REVIEW until the orchestrator's skeptic is folded in (PI-D-013) | any missing |
