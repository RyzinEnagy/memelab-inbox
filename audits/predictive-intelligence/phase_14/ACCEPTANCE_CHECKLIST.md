## Frozen rules of behavioral-1 (fixed here, before any code)

1. Scope. Build only what works without spend: an isolated adapter boundary (an HTTP JSON service on a loopback IP literal, or a subprocess with an environment built from scratch), a structured scenario schema, seed checks, stability checks, cost and failure controls, an LLM metering proxy, and a deterministic LLM-free rule-based scenario generator (`behavioral-rules-1`) as the Phase 15 comparator (A) and fallback. Exercised against a lab-written localhost mock simulator and mock LLM (fixtures, fictional output) and, in the probe only, against MiroFish's unmodified `backend/scripts/run_reddit_simulation.py` as a separate process inside `unshare -n` through the metering proxy to the Phase 03 mock LLM.
2. Approval and mode. The adapter runs only when `predictive.behavioral.approved` is the JSON value true, `predictive.behavioral.mode` is `ON_DEMAND_LOCAL` (any other mode, including per-opportunity or scheduled, is NOT_SUPPORTED) and `predictive.behavioral.kill_switch` is not true. The default config gives SIMULATION_NOT_AVAILABLE with detail NOT_APPROVED. No environment variable or key is read by the lab code.
3. Egress. Endpoint and LLM upstream URLs must be `http://127.0.0.1:<port>` or `http://[::1]:<port>` exactly: no host name (including `localhost`), no userinfo, no other IP, no redirect following, no proxy environment. Anything else is NOT_SUPPORTED with detail EGRESS_NOT_APPROVED. A live route is a code change with change control, not a config switch.
4. Scenario document `memelab.predictive.behavioral_scenario/1`: `kind` BEHAVIORAL_HYPOTHESIS_NOT_A_FORECAST, `fictional` true and a fixed fiction notice; subject (chain, exact mint verified as in the contract, snapshot sha256, decision time); seed reference (seed sha256, cutoff, observation ids and kinds; no observation text); engine (name, mode RULE_BASED, MOCK_SIMULATOR or EXTERNAL_SIMULATOR, pin, model id, declared model training cutoff, run seeds, persona sets, instruction template sha256); hypotheses, each with a label from the fixed vocabulary, named assumptions (kind OBSERVED_FACT, SYNTHETIC_PERSONA_BEHAVIOR or SYNTHETIC_SPECULATION, a code, source refs), source refs that are seed observation ids, a falsifiable monitor (metric and expectation from the fixed vocabulary, window starting at the decision and ending at decision plus the metric's horizon, data source), and `synthetic` true; stability; contamination flags; cost; provenance (adapter version, creation time, run ids, response and trace sha256); refused-claim counts; `doc_sha256` over the rest.
5. Vocabulary. Labels: CATALYST_FOLLOW_THROUGH and RUMOR_FADE (need a CATALYST_EVENT observation; FOLLOW_THROUGH needs its state VERIFIED), ATTENTION_EXHAUSTION, ORGANIC_ATTENTION_CONTINUATION, MANUFACTURED_ATTENTION_DUMP (need a LAB_ATTENTION_PROXY observation), NO_GROUNDED_SCENARIO (no monitor, no assumption). Monitor metrics: the three PRIMARY registry targets (expectation EVENT or NO_EVENT, horizon from the registry), CATALYST_VERIFIED_BY_WINDOW_END (YES or NO, 24 h), ATTENTION_TREND_AT_NEXT_DECISION (EXHAUSTION, STABILITY or ACCELERATION, 24 h). Observation kinds: LAB_ATTENTION_PROXY, CATALYST_EVENT, SOURCE_STATE, QUOTED_PUBLIC_TEXT.
6. No probability (P27). `validate_scenario` refuses, at any depth, a key matching the Phase 13 pattern `abstention.PROB_LIKE`, and any float outside `cost.est_cost_usd`, `cost.cap_usd` and `cost.wall_s`; integers only in the listed count fields. A service response holding any probability-like key or fraction is refused whole (RESPONSE_REFUSED_PROBABILITY). The forecast projection `forecast_entries` holds only strings and passes `abstention.validate_publication`. Agreement counts across runs are never emitted into a forecast document.
7. Seed checks (P28, P41, P45 inputs). `check_seed` refuses a seed when: the mint is not exact; an observation lacks `available_at_utc`, a source ref or a content sha256 that matches its canonical content; an observation is available after the decision (no tolerance); any key at any depth matches the outcome pattern (`label|outcome|matur|realiz|future|after_decision|post_decision|peak|max_price|min_price|drawdown|pnl|profit|first_touch|touch` or the word `ath`); any string holds an ISO date or time after the decision (a bare date counts when it is after the decision's UTC date) or a 10-digit unix time after it; any string matches the frozen injection and secret patterns (instruction overrides such as "ignore previous instructions", role markers such as `system:`, "you are now", "disregard", API key, secret, password, `sk-` tokens, private key blocks, seed phrase, mnemonic, private key, any URL, shell fetch commands, script tags); an observation is itself derived from a behavioral document (source ref starting `behavioral-`, kind of a scenario, or a `BEHAVIORAL` marker: no generated rumor feeds back as observed news); more than 50 observations or a quoted text over 1,000 characters.
8. Request (P41). The service request separates `instructions` (a fixed lab template, sha256 pinned in a test), `quoted_evidence` (each item marked `role: data`, with its observation id) and `synthetic_personas` (fictional archetype codes made by the lab from the persona-set number, never real accounts). Bounds: at most 50 agents, 24 rounds, 64 KB of request.
9. Response coding. Only labels, assumption kinds, metrics and expectations from the vocabulary; source refs must be seed observation ids; a catalyst label without a CATALYST_EVENT observation is refused (UNGROUNDED_CATALYST, P45); claims of kind WALLET_CONTROL or IDENTITY_LINK are refused and counted (never one real person behind related wallets); INSIDER_INTENT is kept only as an assumption of kind SYNTHETIC_SPECULATION; any string with an injection, secret or URL pattern refuses the response. The adapter sets monitor windows from the decision time and the metric's horizon itself.
10. Failure states (P30). Every failure ends SIMULATION_NOT_AVAILABLE with a named detail, never an exception into the caller: NOT_APPROVED, MODE_NOT_ON_DEMAND_LOCAL, KILL_SWITCH, ADAPTER_ABSENT, EGRESS_NOT_APPROVED (NOT_SUPPORTED), KEY_MISSING (HTTP 401 or 403), QUOTA_EXHAUSTED (402 or 429), SERVICE_DOWN, TIMEOUT, SERVICE_ERROR (5xx), BAD_RESPONSE, RESPONSE_REFUSED_PROBABILITY, RESPONSE_REFUSED_INJECTION, UNGROUNDED_CATALYST, NO_LLM_ACTIONS (exit 0 or 200 with zero LLM actions), SCRIPT_EXIT_n, NO_OUTPUT, COST_CAP_REACHED, CIRCUIT_OPEN, SEED_REFUSED. `runtime.simulation_state(config, adapter)` agrees with the adapter on every case.
11. Retries and timeouts. Per request timeout 30 s, per subprocess run 900 s (process group killed); retries only for SERVICE_DOWN, TIMEOUT and SERVICE_ERROR, at most 2, through `runtime.CallGuard` (breaker 5 consecutive failures); never for KEY_MISSING or QUOTA_EXHAUSTED.
12. Cost cap and breaker (P48). Before any call the adapter computes the worst case (calls = agents x rounds + agents + 2, each charged at the per-call ceiling: max prompt characters / 4 tokens at the input price plus the max_tokens ceiling at the output price) and refuses with COST_CAP_REACHED, making 0 calls, when it exceeds `max_cost_usd`. The metering proxy (loopback, OpenAI-compatible POST under `/v1/`) charges every forwarded call its pre-call ceiling, refuses with 429 once the next charge would pass the cap, refuses prompts over 16,000 characters (413), forces `max_tokens` to at most 512, refuses after 200 calls per run, opens its breaker after 5 consecutive upstream failures (later calls refused without reaching the upstream), honours a kill switch, and logs sizes and hashes only. A non-finite or negative cost setting refuses everything. Default `max_cost_usd` is 0 (no spend approved).
13. Contamination (P26). An engine must declare `model_training_cutoff_utc`; when it is missing or after the decision time, the scenario carries LLM_PRETRAINING_CONTAMINATION_RISK and EXPLORATORY_NOT_AS_OF. The rule-based generator declares NOT_APPLICABLE (no pretraining).
14. Stability (P29). Frozen grid: 3 run seeds (101, 202, 303) x 2 persona sets (1, 2), a fixed-settings repeat of the first cell, one run per present observation kind with that kind removed, and one run with no evidence. STABLE only when all 6 grid runs give the identical label set and the repeat gives the identical label set (and an identical response sha256 when the engine declares itself deterministic). Otherwise UNSTABLE: hypotheses kept as exploratory, no dominant scenario. Fewer runs than the grid: NOT_ASSESSED, never STABLE. NOT_SOURCE_GROUNDED when the no-evidence run gives the same non-empty label set (other than NO_GROUNDED_SCENARIO) as the full run. Degraded-source runs are reported (DEGRADED_SOURCE_CHANGES) and are not a stability failure.
15. Rule table `behavioral-rules-1` (deterministic, no randomness, no outcome; a rule whose input is missing does not fire; missing is never favourable):
    - R1: a CATALYST_EVENT with state VERIFIED: CATALYST_FOLLOW_THROUGH, monitor price_path_target_before_invalidation_24h EVENT.
    - R2: a CATALYST_EVENT with any other state: RUMOR_FADE, monitor CATALYST_VERIFIED_BY_WINDOW_END NO.
    - R3: `sc_attention_reversal` = 1, or `sc_attention_trend_ord` = 0 with `sc_lifecycle_late` = 1: ATTENTION_EXHAUSTION, monitor price_path_severe_drawdown_or_halt_24h EVENT.
    - R4: `sc_organic_acceleration` = 1: ORGANIC_ATTENTION_CONTINUATION, monitor price_path_target_before_invalidation_6h EVENT.
    - R5: `sc_attention_suspect` = 1: MANUFACTURED_ATTENTION_DUMP, monitor price_path_severe_drawdown_or_halt_24h EVENT.
    - R6: none fired: NO_GROUNDED_SCENARIO.
    Each fired rule cites the observation ids it read. The rule table's sha256 is pinned by a test.
16. Real seeds. For every development decision (decision time before 2026-10-17T00:00Z) in the Phase 05 feature store, a seed from `socialcat.socialcat_as_of` with the decision's own export (as Phase 10's runner builds it): LAB_ATTENTION_PROXY observations for the seven socialcat values the rules read plus `sc_narrative_tagged` and `sc_channels_n` when not missing, available at the decision; SOURCE_STATE observations CATALYST_TABLES_NOT_EXPORTED and SOCIAL_TABLES_NOT_EXPORTED. No label is read. Expected, stated in advance: every seed passes `check_seed`; no seed holds a CATALYST_EVENT, so R1 and R2 never fire and no catalyst hypothesis exists (P45 on real data); counts of R3 to R6 are reported, never scored.
17. Core unaffected. With the behavioral module blocked from import and the simulator down, Phase 13's runner gives the same outputs as committed (byte-equal except its run logs); the full suite shows no new failure; no `memelab` module other than `behavioral.py` imports it.
18. Gate vocabulary. `MIROFISH_GATE` = BLOCKED (live run: no approved LLM spend; also non-deterministic and P26-contaminated for retrospective use); the simulator path is TEST_ONLY (fixtures and mocks only); the rule-based generator is real code run on real point-in-time seeds but unscored.
