# Hand-checked event trace (Phase 06)

Each case below was worked by hand from the candles first, then run through `memelab/predictive/labels.py`; the code must give exactly the hand label. Part A is a fixture (`tests/fixtures/predictive/labels_hand_trace.json`, written by `probes/make_hand_fixture.py`, checked by `tests/test_predictive_labels.py::test_hand_checked_trace_cases`). Part B is real development decisions picked by a fixed rule (`probes/real_traces.py`, output `evidence/real_traces.json`). Holdout decisions are never used here.

Candle rows are `[start, open, high, low, close, volume]`, 5-minute, UTC. Price-path labels only: a touch is a displayed high or low, not a fill (PRICE_PATH_NOT_PROCEEDS).
