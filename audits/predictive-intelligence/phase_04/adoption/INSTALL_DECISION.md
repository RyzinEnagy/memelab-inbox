# Install decision per component (Phase 04)

Decision values from the phase prompt: INSTALL (a pinned third-party package used as is), ADAPTER (a pinned package used only behind a lab wrapper that limits what it may do), INSPIRED_NEW_CODE (the lab writes its own code from the definitions; the package, if any, stays an oracle), EXTRACT_WITH_LICENSE_REVIEW (code copied under its license with notices), REJECT (not used on the named route). Candidates come from Phase 03 (`phase_03/research/CATEGORY_WINNERS.md`, PI-D-028); review ids in brackets. The numbers are from BAKEOFF.md and `BAKEOFF_RESULTS.json`; every run was offline (`unshare -n`), in a fresh process, with Python 3.13.17, numpy 2.5.3, pandas 3.0.5 and scipy 1.18.1 (the lab's runtime versions).

Where packages go (PI-D-032 as amended by PI-D-035): the lab's own runtime keeps numpy as its only third-party dependency; install commands are built only by `runtime.install_argv`, which refuses a lock with any per-line option before pip starts; `memelab/predictive/runtime.py` uses the standard library only. INSTALL and ADAPTER packages exist only in a research venv installed from `docs/predictive-intelligence/locks/research-py313.txt` (BOM_LOCKS.md), for offline training, evaluation, oracles and comparators. A model that a later phase wants to serve inside the lab is exported as plain numbers (coefficients, calibration parameters) into a JSON model card that the numpy core reads; no pickle is ever loaded by the lab (scikit-learn and statsmodels persist only as pickles, Phase 03 gate).

EXTRACT_WITH_LICENSE_REVIEW was not needed for any component: no third-party code was copied into the lab. If Phase 19 wants ADWIN rather than Page-Hinkley, porting river's BSD-3 ADWIN with its notice would be that route and needs a license note first.

## Error states and circuit breakers (the fallback design)

The statistical engine runs offline with numpy only and without behavioral simulation; this was executed, not stated: the four numpy approaches ran in a venv that holds numpy 2.5.3 and nothing else, inside `unshare -n`, and produced the same predictions byte for byte as in the full research venv (BAKEOFF.md). `runtime.py` turns every absent optional piece into a named state:

| Absent or failing | State | Forecast effect (contract abstain reason) |
|---|---|---|
| optional library (ImportError, ModuleNotFoundError) | DEPENDENCY_MISSING | MODEL_NOT_SELECTED |
| model file missing / hash differs | MODEL_WEIGHTS_MISSING / MODEL_HASH_MISMATCH | MODEL_NOT_SELECTED |
| network down, DNS failure, timeout, URLError | NETWORK_UNAVAILABLE | SOURCE_STALE |
| 5 consecutive failures / call cap / cost cap | CIRCUIT_OPEN / CALL_CAP_REACHED / COST_CAP_REACHED (call refused before it is made) | SOURCE_STALE |
| any other exception, SystemExit included (a component or CLI calling `sys.exit`), a GPU or CUDA error, MemoryError, NaN refusal | COMPONENT_ERROR (error class kept) | MODEL_NOT_SELECTED |
| a returned error response, when the caller supplies `is_failure` (a callable must otherwise raise) | BAD_RESPONSE (counts toward the breaker) | SOURCE_STALE |
| non-finite or negative cost setting | COST_CAP_REACHED for every call (fails closed) | SOURCE_STALE |
| malformed config (a section that is not a JSON object) | OFF: SIMULATION_NOT_AVAILABLE NOT_APPROVED; `contract.enabled` returns False | none |
| KeyboardInterrupt, GeneratorExit | not contained, on purpose (an operator's stop; the generator protocol) | not applicable |
| GPU | NOT_REQUIRED (the engine is CPU-only; never probed) | none |
| crawler | NOT_REQUIRED (v1 targets use no crawled input) | none |
| Zep, LLM key, quota, unreachable simulator, exit 0 without LLM actions, not approved | SIMULATION_NOT_AVAILABLE | none; `behavioral_scenarios` stays empty |
| backtesting engine | BACKTEST_NOT_AVAILABLE (UNVERIFIED if merely importable) | none; never a combined claim (P34) |

No state reads an environment variable or a key; the P30 tests replace `os.environ` with a mapping that raises on any key-like name. Every probe in `capability_report` runs inside `guarded`, an adapter's `llm_actions` counts only as a positive int, and `dependency_state` refuses dotted names because probing them imports the parent package (repair pass, PI-D-035). Pacing defaults to the frozen 6 calls a minute, 1,200 calls a run and a breaker after 5 consecutive failures (`ACCEPTANCE["api_limits"]`).

## License position (summary)

Every adopted package is permissive (BSD-3-Clause, MIT); the wheels' own license files were read (BOM_LOCKS.md). No AGPL or GPL code is copied into the lab: the copyleft gate scans every code file in the working tree (411 at the repair commit, `audits/`, root scripts and the copied skeptic scripts included) against license markers and 5,393 fingerprints of the pinned MiroFish and black-it sources and finds nothing; two license detectors that hold license titles as data are exempt from the marker check only (P31). Copies shorter than 15 normalized lines, or rewritten code, can pass. Not legal advice.
