Install route (decision PI-D-032): `python -m pip install --require-hashes --only-binary=:all: --no-deps -r <lock>` into a dedicated venv. `--require-hashes` refuses any file whose sha256 is not listed, `--only-binary=:all:` refuses every sdist (so no `setup.py` or build backend ever runs, P32), `--no-deps` installs exactly the listed pins and resolves nothing else. `memelab/predictive/runtime.check_lock` refuses a lock with an unpinned, unhashed, URL, VCS, path, editable, nested or alternate-index line (tests P32). There is still no requirements file at the repository root and no change to how the lab itself installs (`pip install pytest numpy`, README).

## How the locks were made and checked

1. `uv pip compile <in> --override pandas==3.0.5 --python-version 3.13 --universal --generate-hashes --only-binary :all:` (uv 0.11.32). Inputs: `evidence/research-py313.in` and `numpy==2.5.3`; override file `evidence/research-py313.overrides.txt`. The override exists because lifelines 0.30.3 declares `pandas<3.0` while the lab runs pandas 3.0.5 (Phase 03 LL-1); `pip check` in the installed venv reports exactly that one conflict, and lifelines ran on pandas 3.0.5 in every bake-off and rollback run.
2. `prototypes/build_lock.py` read PyPI's JSON for each exact `name==version` (35 version reads across the two lock builds, cached, free) and kept only the sha256 of CPython 3.13 wheels for Linux x86_64 (manylinux), Windows x86_64 and macOS arm64, plus pure-Python wheels. Every kept hash had to equal PyPI's digest and appear in uv's lock, and every pin had to keep a wheel for all three platforms: 0 problems (`evidence/research-py313.bom.json`, `evidence/core-py313.bom.json`).
3. `pip download --require-hashes --only-binary=:all: --no-deps` (pip 24.0, system Python 3.13) once per platform, with `--platform win_amd64` and `--platform macosx_*_arm64` for the two foreign ones: 30 wheels per platform, each sha256 in the lock (`evidence/wheelhouse_check.txt`; 105.6 MB Linux, 93.6 MB Windows, 69.3 MB macOS). This proves a Windows or Mac install resolves every pin to a hashed wheel without building anything.
4. Offline install into a throwaway venv (pip 26.2.2) from the Linux wheelhouse inside `unshare -n`, smoke of four bake-off approaches, uninstall of all 30 names: `pip freeze` and a sha256 manifest of every file in site-packages equal before and after (`prototypes/rollback_demo.py`, `evidence/rollback_demo.json`, `rollback_clean: true`). The system interpreter's `pip freeze` sha256 was `4bbf5c51...` at the start of the phase and is the same at the end.

The bake-off venv itself (`/home/claude/pi_research/venvs/p04_bundle`) was installed the same way from a wider lock (`evidence/bakeoff-bundle.in`, lock sha256 `b19ef317...`, kept outside the repository because it is 900 lines of hashes for every platform) that also held the candidates later rejected (pandera, Mesa) or deferred (statsmodels, arch, crepes, interpret-core). Mesa ran in its own venv with its `network` extra (`mesa[network]==3.5.1`), because a plain `mesa` install cannot be imported (INSTALL_DECISION.md).

## Licenses inside the wheels

`prototypes/wheel_licenses.py` opened each of the 30 Linux wheels as a zip (never installed or imported there) and read every LICENSE, COPYING or NOTICE file (`evidence/wheel_licenses.json`). Every wheel ships at least one license file. GPL or LGPL text appears only as notices of bundled third-party components or as references: numpy and scipy bundle the GCC runtime libraries (`libgfortran`, GPL-3.0-or-later WITH GCC-exception-3.1; `libquadmath`, LGPL-2.1-or-later) next to OpenBLAS (BSD-3-Clause), and the GPL-3 text itself names the AGPL in its section 13, which is why an AGPL pattern matches there; pillow, pandas, scikit-learn and typing_extensions carry similar notices for vendored pieces. These are the same numpy files the lab already runs. No wheel is redistributed by the lab and no code from any wheel is copied into it; the P31 fingerprint gate is about copied source, not about installed libraries.

Root licenses of the adopted projects were read at their pins in Phase 03 (LICENSE_AND_SECURITY_GATE.md): scikit-learn BSD-3-Clause, LightGBM MIT (keep the third-party notices if redistributed), MAPIE BSD-3-Clause with two MIT notices, purgedcv MIT, river BSD-3-Clause (Rust crates permissive), lifelines MIT.
