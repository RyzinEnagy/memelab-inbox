- D-BT-010 (2026-10-23, Phase 01): the discovery universe is the union of theses and rejections across all git versions of data/state/latest.json, not the latest file (1,801 vs 701 theses).
- D-BT-011 (2026-10-23, Phase 01): exact historical execution is BLOCKED (no reserves/ticks/bins source); historical fills use LIQ_SNAPSHOT_APPROX or QUOTE_OBSERVED with labels.
- D-BT-012 (2026-10-23, Phase 03): no reviewed repository reaches the 70-point adoption threshold (best: slotfish 65.10 primary, 59.30 blind). Build a purpose-built engine in `memelab/backtest`, informed by ideas from slotfish, basana, sol-trade and backtesting.py, with independent test oracles. No copyleft or unlicensed code copied. To be confirmed by the Phase 04 bake-off.
- D-BT-013 (2026-10-23, Phase 03): engine fill conventions fixed from review findings: next bar open after decision plus latency (never the signal bar), gap-through stops fill at the open, stop-loss wins when stop and take-profit are both inside one bar, PumpSwap priced on effective quote reserves (vault + signed virtual_quote_reserves).
- D-BT-014 (2026-10-23, Phase 04): bake-off confirms D-BT-012. Engine, CPMM math, validation and analytics are reimplemented (no new runtime dependency). backtesting.py and vectorbt are audit-only external oracles in isolated venvs. CLMM/DLMM historical fills are not implemented (UNSUPPORTED_POOL unless a quote observed at decision time exists).
- D-BT-015 (2026-10-23, Phase 04): Maxun: AGPL source integration NO-GO without Elving's legal decision; self-hosting not authorized; a thin Maxun Cloud API client is license-compatible and is evaluated in Phase 06A.
- D-BT-016 (2026-10-23, Phase 05): `tools/release_audit.py` gains five narrow reviewed-hit entries (backtesting audit notes, prompt package, isolated smoke scripts, one env-var-name match in a smoke output, backtest refusal-list tests). Code under `memelab/backtest/` gets no exemption.
- D-BT-017 (2026-10-23, Phase 05): bt schema is created lazily by the backtest package, not by `db.init_db`. Backfilled market bars are available at end + provider lag (modeled, flagged); later revisions only from their own observation time.
- D-BT-018 (2026-10-23, Phase 06): backtest data lives in its own SQLite file `data/backtest/bt.sqlite` (env `MEMELAB_BT_DB`), gitignored, with raw provider responses under `data/backtest/raw/`. The lab's tracked database is never written by the backtest package. A small real fixture is committed under `tests/fixtures/backtest/real/`.
- D-BT-019 (2026-10-23, Phase 06): corpus resume counts a mint as done only after its bar fetches complete (`CORPUS_MINT_DONE` marker), not when its pool list was fetched. Corrupted mint strings in the lab's exports are reported (GAPS C4) and never merged by similarity.
- D-BT-020 (2026-10-23, Phase 06A): Maxun NOT_ADOPTED (EXISTING_TOOL_WINS for the catalyst watch; release watch uses the GitHub Releases API). Public pages enter the lab only through `memelab/backtest/sources/webcapture.py` with use-case allowlists, page caps and a claim fingerprint; Maxun is refused as a runtime collector. The evaluation robot stays idle with no schedule.
- D-BT-021 (2026-10-23, Phase 07): PumpSwap fees are per pool (observed 0.30%, 0.55%, 1.25%); historical runs use 1.25% unless the pool's fee was observed, labeled ASSUMED_UPPER_OBSERVED_TIER. PumpSwap pricing uses effective quote reserves (vault plus the signed virtual quote reserve at byte 245 of the pool account), confirmed against live Jupiter quotes within 0.02%.
- D-BT-022 (2026-10-23, Phase 09): historical catalysts come from the lab's own contemporaneous records (launch monitor in the committed state exports, first value kept; catalyst tables when present). Claimed event times are never decision times. Wallet observations count as selling only when they are verified swap sales with an availability time; transfers, custody moves and inferences never do.
- D-BT-023 (2026-10-23, Phase 10): the research runner lives in the existing CLI as `python -m memelab backtest` (status, run). A bar that crashes more than 50% through a stop and closes below it is exited at its close, not at the stop. Run ids include a content hash of the backtest package. The discovery baseline makes one attempt only.
